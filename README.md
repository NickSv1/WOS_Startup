# WOS_Startup — Knodle

AI-powered savings coach demo for Weekend of Startups.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Enter an email on the landing page to unlock the live map at `/app`.

## Demo

The map is **Stephan**: Everyday + Board fund + Super, saving for a **$1,000 Channel Islands surfboard**. Click the goal for the week-by-week path. **Overspend** (drinks last night) lengthens the path and offers cuts or a later date.
